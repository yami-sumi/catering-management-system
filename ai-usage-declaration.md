# AI Usage Declaration

## 1. Project Information

**Project:** Catering Business Management System  
**Course:** COMP018 – Database Administration  
**Repository:** https://github.com/yami-sumi/catering

## 2. Purpose of This Declaration

This document records the use of artificial intelligence tools, if any, during the planning, development, debugging, testing, and documentation of the Catering Business Management System.

The declaration is intended to be transparent about AI assistance and to distinguish suggestions generated by AI from work reviewed, tested, and accepted by the project group.

## 3. AI Tool Identified in the Project Materials

The existing project declaration identifies **ChatGPT (OpenAI)** as an AI tool used by the group.

Before submission, the group should confirm that this list includes every AI tool actually used by its members. Add other tools only when their use can be accurately declared.

## 4. Areas of AI Assistance

The previous project declaration records AI assistance in the following areas:

| Area | Type of assistance recorded |
|---|---|
| Backend development | Explanations and guidance related to Node.js, Express.js, PostgreSQL connections, and API operations |
| Database work | Assistance with SQL queries and database verification procedures |
| CRUD testing | Suggestions for commands used to test POST, GET, PUT, and DELETE operations |
| Troubleshooting | Help interpreting errors, checking API routes, and identifying record IDs |
| Documentation | Assistance drafting and improving project documentation |

The group must review this table and remove or revise any item that does not accurately describe how its members used AI.

## 5. Human Review and Responsibility

AI-generated explanations, code suggestions, commands, and documentation are not automatically assumed to be correct.

Project members are responsible for:

- Reviewing AI-generated material before using it.
- Comparing technical descriptions with the actual source code and database structure.
- Running and checking commands before relying on their results.
- Testing application behavior and database operations.
- Correcting inaccurate, incomplete, or unsupported statements.
- Understanding and being able to explain the submitted work.

The project group remains responsible for the final source code, database scripts, test results, and documentation.

## 6. Limitations of AI Assistance

AI tools may produce inaccurate, outdated, incomplete, or unsuitable suggestions. Generated content may also describe a feature that is planned but not implemented.

For that reason, the group should verify all AI-assisted material against the current project implementation. AI assistance does not replace actual testing, source-code review, or the group's understanding of the system.

## 7. Privacy and Security

Members should not submit passwords, database credentials, session secrets, private customer information, or other confidential project data to AI tools.

Secrets must be kept in local environment files and excluded from shared repositories and documentation.

## 8. Declaration

We acknowledge that AI assistance was used in connection with parts of the development and/or documentation process, as confirmed by the project group.

We have reviewed the AI-assisted material included in the final submission and accept responsibility for its accuracy, originality, and compliance with our course requirements.

**Before submission:** Each group member should confirm that this declaration accurately reflects the group's actual AI use. Update the tool list and activities if necessary.
